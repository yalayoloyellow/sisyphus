# Sisyphus 1.0.3

Минималистичный терминальный органайзер для разгрузки мозга.

Заметки, задачи и финансы в одном чистом CLI. С поддержкой Telegram-бота для уведомлений.

## Изменения в 1.0.3

- Убран автозапуск Telegram-бота в фоне. Теперь бот запускается только явно: `python -m sisyphus --bot`
- Повышена надёжность отправки сообщений (3 попытки при ошибках, фиксированные задержки 4 секунды)
- Убрана Markdown-разметка из сообщений бота
- Улучшена обработка ошибок при старте бота (3 попытки подключения)

## Установка и запуск

```bash
pip install -r requirements.txt
python -m sisyphus
```

Или:

```bash
python launch.py
```

При первом запуске данные автоматически создадутся в ~/Documents/Sisyphus (кросс-платформенно).

## Настройка Telegram-бота и рассылки

В CLI:

- `/bot token <токен>` — задать токен бота (бот автоматически запустится в фоне при следующем старте программы)
- `/notify daily 09:00` — ежедневная рассылка
- `/notify weekdays 09:00` — по будням
- `/notify weekly mon 09:00` — еженедельно
- `/notify-` — отключить рассылку
- `/forcenotify` — принудительная рассылка прямо сейчас

Бот отвечает только на `/my` (твои задачи по всем проектам, в т.ч. из групп).

## Основные команды

- `текст` — заметка
- `@user текст` — задача
- `+100 текст` / `-50 текст` — финансы
- Enter — показать список
- `/del N` — удалить
- `/done N` — отметить выполненным
- `/e N текст` — редактировать
- `/rename <новое_имя>` — переименовать текущий проект
- `/u` / `/r` — undo / redo
- `/fin` — список финансов
- `/export` — экспорт в .xlsx (3 листа)
- `/m` — проекты
- `/h` — справка
- `/q` — выход

## Cross-platform

Pure Python (pathlib). Data in ~/Documents/Sisyphus (or fallback). Same on macOS/Linux/Windows.

## Философия

Минималистичный дизайн, ничего лишнего, один источник правды (нумерация и данные в core). No extra text on startup. Bare header.
