# Sisyphus 1.0.4.3

Минималистичный терминальный органайзер (только задачи).

Только `@username текст`. Принудительная рассылка `/notify`. Просмотр задач по человеку `/tasks @user` по всем проектам.

1.0.4.3 — только задачи, минимализм, чистый релиз (with rich for beautiful centered UI).

## Установка и запуск

```bash
pip install -r requirements.txt
python -m sisyphus
```

Или:

```bash
python launch.py
```

При первом запуске данные автоматически создадутся в ~/Documents/Sisyphus (кросс-платформенно).

## Настройка Telegram-бота и рассылки

В CLI:

- `/bot token <токен>` — задать токен бота (для отправки уведомлений)
- `/notify` — принудительная рассылка прямо сейчас (использует force_notify)

(Старая scheduled-рассылка и регистрация через /my удалены.)

## Основные команды (только задачи)

- `@user текст` — задача (plain text без @ игнорируется)
- Enter — показать список задач
- `/del N [N2..]` — удалить запись(и)
- `/done N [N2..]` — отметить выполненным
- `/done` — архив выполненных
- `/e N текст` — редактировать запись
- `/m [имя]` — список проектов / открыть проект
- `/p имя` — создать проект
- `/p- имя` — удалить проект
- `/rename имя` — переименовать текущий проект
- `/u` / `/r` — undo / redo
- `/notify` — принудительная рассылка сейчас
- `/tasks @username` — все открытые задачи человека по всем проектам
- `/bot token <токен>` — задать токен для уведомлений (опционально)
- `/h` — эта справка
- `/q` — выход

## Cross-platform

Pure Python (pathlib). Data in ~/Documents/Sisyphus (or fallback). Same on macOS/Linux/Windows.

## Философия

Минималистичный дизайн, ничего лишнего, один источник правды (нумерация и данные в core). No extra text on startup. Bare header.
